## 👨‍💻 Обо мне

Frontend-разработчик с **4 годами коммерческого опыта** на React и TypeScript. Разрабатываю SPA и десктоп-приложения на Electron с нуля: от архитектуры и интеграции с API до тестов, CI/CD и поддержки в продакшене.

- 🏢 Сейчас — **«Альфаматика»**: приложение для терминалов самообслуживания, которое работает у **6+ крупных компаний** — «Аэрофлот», «Газпром», «МосЭнергосбыт» и других
- 🧩 Создаю шаблоны проектов и библиотеки переиспользуемых компонентов
- 👀 Провожу код-ревью и наставляю младших разработчиков
- 🤖 Активно использую AI-инструменты (Claude Code) — рутина быстрее, больше времени на архитектуру и качество
- 🌱 Изучаю бэкенд: Node.js, NestJS, Prisma
- 🎯 Цель — архитектура фронтенда и техлидство
